## Обзор системы обнаружения

Система обнаружения циклонов в ArcticCyclone основана на многокритериальном подходе, который позволяет находить циклоны с использованием различных метеорологических параметров и физических характеристик. Это обеспечивает более надежное и точное обнаружение по сравнению с однокритериальными методами.

Основные принципы системы обнаружения:

1. **Модульность**: Каждый критерий реализован как отдельный класс, что позволяет легко добавлять новые критерии
2. **Настраиваемость**: Все параметры критериев могут быть настроены через конфигурационный файл
3. **Комбинирование**: Результаты нескольких критериев могут комбинироваться для повышения точности
4. **Валидация**: Система валидации проверяет достоверность найденных кандидатов

## Архитектура детектора

Центральным компонентом системы обнаружения является класс `CycloneDetector`, который координирует работу всех критериев.

### Основные компоненты

1. **CycloneDetector**: Основной класс детектора
2. **CriteriaManager**: Менеджер критериев обнаружения
3. **BaseCriterion**: Базовый класс для всех критериев
4. **DetectionValidator**: Валидатор найденных кандидатов

### Рабочий процесс

1. Инициализация детектора с параметрами из конфигурации
2. Регистрация активных критериев
3. Для каждого временного шага:
   - Применение всех активных критериев
   - Сбор кандидатов от каждого критерия
   - Создание объектов Cyclone из кандидатов
   - Валидация и фильтрация результатов

## Критерии обнаружения

### Минимум давления

Критерий `pressure_minimum` ищет локальные минимумы в поле давления на уровне моря.

#### Физическая основа

Циклоны являются областями пониженного атмосферного давления. Поиск локальных минимумов в поле давления - самый прямолинейный и часто используемый метод обнаружения циклонов.

#### Реализация

Используется двумерный фильтр (`scipy.ndimage.minimum_filter`) для нахождения пикселей, которые являются локальными минимумами в определенной окрестности (например, 5x5 ячеек сетки).

#### Параметры

- `pressure_threshold`: Максимальное давление для рассмотрения (гПа)
- `gradient_threshold`: Минимальный градиент давления (гПа/100км)
- `window_size`: Размер окна для поиска локальных минимумов
- `smooth_sigma`: Параметр сглаживания поля давления

#### Сильные стороны

- Простота и вычислительная эффективность
- Эффективность для хорошо выраженных, зрелых циклонов

#### Слабые стороны

- Склонен находить незначительные понижения давления
- Может создавать множественные обнаружения внутри одной большой системы
- Требует постобработки и валидации

### Завихренность

Критерий `vorticity` ищет максимумы относительной завихренности на уровне 850 гПа.

#### Физическая основа

Циклоническое движение характеризуется положительной относительной завихренностью в северном полушарии. Этот критерий идентифицирует динамический центр вращения, который может не идеально совпадать с минимумом давления, особенно в развивающихся или окклюзированных системах.

#### Реализация

Рассчитывается относительная завихренность из компонентов ветра (`vort = dv/dx - du/dy`). Используется фильтр максимумов (`scipy.ndimage.maximum_filter`) для нахождения центров вращения.

#### Параметры

- `vorticity_threshold`: Минимальная завихренность (1/с)
- `pressure_level`: Уровень давления для анализа (гПа)
- `window_size`: Размер окна для поиска локальных максимумов
- `smooth_sigma`: Параметр сглаживания поля завихренности

#### Сильные стороны

- Отлично подходит для идентификации динамически активных систем
- Может обнаруживать циклоны на ранних стадиях развития
- Менее чувствителен к широким, слабым полям давления

#### Слабые стороны

- Может быть "шумным", идентифицируя маломасштабные зоны сдвига
- Требует тщательной настройки пороговых значений

### Градиент давления

Критерий `pressure_gradient` идентифицирует области с сильным градиентом давления.

#### Физическая основа

Сильный градиент давления подразумевает сильные ветры (приближение геострофического ветра). Интенсивные циклоны связаны с плотно упакованными изобарами.

#### Реализация

Рассчитывается величина вектора градиента давления (`sqrt((dP/dx)^2 + (dP/dy)^2)`). Идентифицируются области, где это значение превышает заданный порог.

#### Параметры

- `gradient_threshold`: Минимальный градиент давления (гПа/100км)

#### Сильные стороны

- Хорошо подходит для выбора только интенсивных, динамически значимых систем

#### Слабые стороны

- Не является основным методом обнаружения
- Лучше использовать как вторичный критерий валидации

### Лапласиан давления

Критерий `pressure_laplacian` использует лапласиан поля давления для обнаружения циклонов.

#### Физическая основа

Лапласиан (∇²) поля давления выделяет области максимальной кривизны. Большое положительное значение в ∇²P является надежным индикатором минимума давления (дна "чашки").

#### Реализация

Вычисляются вторые частные производные (`d²P/dx² + d²P/dy²`). Ищутся локальные максимумы в этом поле.

#### Параметры

- `laplacian_threshold`: Порог для лапласиана давления (Па/км²)
- `smooth_sigma`: Параметр сглаживания поля давления
- `window_size`: Размер окна для поиска локальных максимумов

#### Сильные стороны

- Математически более надежный для идентификации центра области пониженного давления
- Менее чувствителен к маломасштабному шуму в поле давления

#### Слабые стороны

- Более вычислительно интенсивен, чем простой поиск минимумов

### Замкнутые контуры

Критерий `closed_contour` ищет замкнутые изобары вокруг центра циклона.

#### Физическая основа

Хорошо развитые циклоны характеризуются замкнутыми изобарами. Этот критерий помогает идентифицировать системы с четко выраженной циркуляцией.

#### Реализация

Анализируются изобары с определенным интервалом. Проверяется, являются ли они замкнутыми контурами.

#### Параметры

- `contour_interval`: Интервал изобар (гПа)
- `min_contours`: Минимальное количество замкнутых контуров

#### Сильные стороны

- Помогает идентифицировать хорошо развитые циклоны
- Хорошо работает в сочетании с другими критериями

#### Слабые стороны

- Может пропускать слабые или развивающиеся системы
- Требует точной настройки параметров

### Порог скорости ветра

Критерий `wind_threshold` отбирает циклоны с минимальной скоростью ветра.

#### Физическая основа

Циклоны связаны с усилением ветра. Этот критерий помогает исключить слабые системы без значительной циркуляции.

#### Реализация

Рассчитывается скорость ветра из компонентов (`sqrt(u² + v²)`). Идентифицируются области, где скорость превышает заданный порог.

#### Параметры

- `min_speed`: Минимальная скорость ветра (м/с)

#### Сильные стороны

- Помогает исключить слабые системы
- Прост в реализации и интерпретации

#### Слабые стороны

- Не идентифицирует центр циклона напрямую
- Может пропускать циклоны с несимметричной структурой ветра

## Комбинирование критериев

Система позволяет комбинировать несколько критериев для повышения точности обнаружения.

### Логика комбинирования

1. Каждый активный критерий независимо применяется к данным
2. Результаты всех критериев собираются в общий список кандидатов
3. Кандидаты, найденные несколькими критериями, могут получать более высокий вес
4. Валидация проверяет физическую достоверность кандидатов

### Пример конфигурации

```yaml
detection:
  criteria:
    pressure_minimum:
      enabled: true
      pressure_threshold: 1010.0
      gradient_threshold: 0.5
    vorticity:
      enabled: true
      vorticity_threshold: 5.0e-5
      pressure_level: 850
    wind_threshold:
      enabled: true
      min_speed: 15.0
```

## Настройка критериев

Критерии настраиваются через конфигурационный файл `config.yaml`.

### Общая структура

```yaml
detection:
  min_latitude: 65.0
  criteria:
    # Критерий минимума давления
    pressure_minimum:
      enabled: true
      pressure_threshold: 1010.0
      gradient_threshold: 0.5
      window_size: 5
      smooth_sigma: 1.0
    
    # Критерий завихренности
    vorticity:
      enabled: true
      vorticity_threshold: 5.0e-5
      pressure_level: 850
      window_size: 3
      smooth_sigma: 1.0
    
    # Критерий замкнутых контуров
    closed_contour:
      enabled: false
      contour_interval: 2.0
      min_contours: 2
    
    # Критерий порога скорости ветра
    wind_threshold:
      enabled: true
      min_speed: 15.0
    
    # Критерий лапласиана давления
    pressure_laplacian:
      enabled: true
      laplacian_threshold: 0.00015
      smooth_sigma: 3
      window_size: 3
```

### Рекомендации по настройке

#### Для арктических условий

- `min_latitude`: 65.0-70.0°N
- `pressure_threshold`: 1010-1015 гПа (арктические циклоны часто имеют более высокое давление)
- `vorticity_threshold`: 2-5×10⁻⁵ с⁻¹
- `wind_threshold`: 10-15 м/с

#### Для тропических циклонов

- `pressure_threshold`: 1000-1010 гПа
- `vorticity_threshold`: 10-20×10⁻⁵ с⁻¹
- `wind_threshold`: 15-20 м/с

## Создание пользовательских критериев

Система поддерживает создание пользовательских критериев обнаружения.

### Базовый класс

Все критерии должны наследоваться от `BaseCriterion`:

```python
from detection.criteria import BaseCriterion
from core.exceptions import DetectionError
import xarray as xr
import numpy as np

class MyCustomCriterion(BaseCriterion):
    def __init__(self, min_latitude: float = 70.0, threshold: float = 1.0):
        self.min_latitude = min_latitude
        self.threshold = threshold
    
    def apply(self, dataset: xr.Dataset, time_step) -> List[Dict]:
        # Реализация критерия
        pass
```

### Регистрация критерия

```python
from detection.criteria import CriteriaManager
from detection.tracker import CycloneDetector

# Создание менеджера критериев
criteria_manager = CriteriaManager()

# Регистрация пользовательского критерия
criteria_manager.register_criterion("my_custom", MyCustomCriterion(threshold=995.0))

# Создание детектора с пользовательским критерием
detector = CycloneDetector(min_latitude=70.0)
detector.criteria_manager = criteria_manager
detector.set_criteria(["my_custom"])
```

### Пример пользовательского критерия

```python
import xarray as xr
import numpy as np
import logging
from typing import Dict, List
from detection.criteria import BaseCriterion
from core.exceptions import DetectionError

logger = logging.getLogger(__name__)

class TemperatureAnomalyCriterion(BaseCriterion):
    """
    Критерий обнаружения циклонов на основе температурных аномалий.
    
    Ищет области с отрицательными температурными аномалиями,
    характерными для холодных циклонов.
    """
    
    def __init__(self, min_latitude: float = 70.0, 
                 anomaly_threshold: float = -5.0,
                 pressure_level: int = 850):
        """
        Инициализация критерия температурных аномалий.
        
        Аргументы:
            min_latitude: Минимальная широта для анализа (градусы с.ш.)
            anomaly_threshold: Порог температурной аномалии (K)
            pressure_level: Уровень давления для анализа (гПа)
        """
        self.min_latitude = min_latitude
        self.anomaly_threshold = anomaly_threshold
        self.pressure_level = pressure_level
    
    def apply(self, dataset: xr.Dataset, time_step) -> List[Dict]:
        """
        Применяет критерий температурных аномалий.
        
        Аргументы:
            dataset: Набор метеорологических данных xarray
            time_step: Временной шаг для анализа
            
        Возвращает:
            Список кандидатов в циклоны
        """
        try:
            # Проверка наличия температурных данных
            if 't' not in dataset and 'temperature' not in dataset:
                logger.warning("Переменная температуры не найдена в наборе данных")
                return []
            
            temp_var = 't' if 't' in dataset else 'temperature'
            
            # Выбор временного шага и уровня давления
            time_data = dataset.sel(time=time_step)
            
            # Проверка наличия измерения уровня давления
            if 'level' in time_data.dims:
                # Выбор ближайшего доступного уровня
                available_levels = time_data.level.values
                closest_level = available_levels[
                    np.abs(available_levels - self.pressure_level).argmin()
                ]
                temp_data = time_data[temp_var].sel(level=closest_level)
            else:
                temp_data = time_data[temp_var]
            
            # Применение маски арктического региона
            arctic_mask = temp_data.latitude >= self.min_latitude
            arctic_temp = temp_data.where(arctic_mask, drop=True)
            
            # Расчет зонального среднего температуры
            zonal_mean = arctic_temp.mean(dim='longitude')
            
            # Интерполяция зонального среднего на сетку
            zonal_mean_interp = zonal_mean.interp(
                latitude=arctic_temp.latitude, 
                method='linear'
            )
            
            # Расчет температурной аномалии
            temp_anomaly = arctic_temp - zonal_mean_interp
            
            # Поиск областей с отрицательными аномалиями
            cold_areas = temp_anomaly <= self.anomaly_threshold
            
            # Получение координат кандидатов
            candidate_indices = np.where(cold_areas.values)
            
            candidates = []
            for i in range(len(candidate_indices[0])):
                lat_idx = candidate_indices[0][i]
                lon_idx = candidate_indices[1][i]
                
                latitude = float(arctic_temp.latitude.values[lat_idx])
                longitude = float(arctic_temp.longitude.values[lon_idx])
                anomaly = float(temp_anomaly.values[lat_idx, lon_idx])
                
                candidate = {
                    'latitude': latitude,
                    'longitude': longitude,
                    'temperature_anomaly': anomaly,
                    'criterion': 'temperature_anomaly'
                }
                
                candidates.append(candidate)
            
            logger.debug(f"Критерий температурных аномалий нашел {len(candidates)} кандидатов")
            return candidates
            
        except Exception as e:
            error_msg = f"Ошибка при применении критерия температурных аномалий: {str(e)}"
            logger.error(error_msg)
            raise DetectionError(error_msg)
```

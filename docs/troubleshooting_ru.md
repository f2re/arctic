## Обзор системы логирования

Система ArcticCyclone использует стандартное логирование Python для отслеживания событий и ошибок. Логирование настраивается через конфигурационный файл или командную строку.

### Уровни логирования

- **DEBUG**: Подробная отладочная информация (только для разработчиков)
- **INFO**: Общая информация о ходе выполнения
- **WARNING**: Предупреждения о возможных проблемах
- **ERROR**: Ошибки, препятствующие нормальному выполнению
- **CRITICAL**: Критические ошибки, приводящие к завершению программы

### Настройка логирования

```bash
# Включение отладочного режима
python main.py --log-level DEBUG ...

# Режим только ошибок
python main.py --log-level ERROR ...
```

### Файлы логов

Логи сохраняются в файл, указанный в конфигурации:
```yaml
# config.yaml
core:
  logging:
    level: 'INFO'
    file: 'arctic_cyclone.log'
```

## Распространенные проблемы

### Проблемы с данными

#### Ошибка: "Переменная давления не найдена в наборе данных"

**Симптомы**: 
- Сообщение об ошибке: "Не удается определить переменную давления в наборе данных"
- Программа завершается с ошибкой на этапе обнаружения

**Причины**:
1. Неправильное разделение переменных на surface/pressure_levels в конфигурации
2. Данные загружаются с неправильным dataset_type
3. Переменная давления отсутствует в запрошенных данных

**Решения**:
1. Проверьте конфигурацию источника данных:
   ```yaml
   data:
     sources:
       ERA5:
         variables: ['msl']  # Для поверхностных данных
         # или
         variables: ['z', 'u', 'v', 't', 'vo']  # Для данных на уровнях давления
   ```

2. Убедитесь, что dataset_type соответствует запрашиваемым переменным:
   ```yaml
   parameters:
     dataset_type: 'surface'  # Для msl
     # или
     dataset_type: 'pressure_levels'  # Для z, u, v, t, vo
   ```

3. Проверьте, что переменная давления включена в список запрашиваемых переменных

#### Ошибка авторизации ERA5

**Симптомы**:
- Сообщение об ошибке: "401 Unauthorized" или "Invalid API key"
- Программа не может загрузить данные из CDS

**Причины**:
1. Неправильный API-ключ в файле ~/.cdsapirc
2. Файл ~/.cdsapirc отсутствует или находится в неправильной директории
3. Проблемы с подключением к интернету

**Решения**:
1. Проверьте содержимое файла ~/.cdsapirc:
   ```
   url: https://cds.climate.copernicus.eu/api/v2
   key: YOUR_ACTUAL_API_KEY_HERE
   ```

2. Убедитесь, что файл находится в домашней директории пользователя:
   ```bash
   # Linux/macOS
   ls -la ~/.cdsapirc
   
   # Windows
   dir %USERPROFILE%\.cdsapirc
   ```

3. Проверьте API-ключ на сайте CDS:
   - Перейдите в профиль пользователя
   - Скопируйте актуальный API-ключ
   - Обновите файл ~/.cdsapirc

#### Медленная загрузка данных

**Симптомы**:
- Долгое ожидание при загрузке данных
- Программа "зависает" на этапе получения данных

**Причины**:
1. Большие объемы запрашиваемых данных
2. Медленное интернет-соединение
3. Проблемы с серверами CDS
4. Отсутствие кэширования

**Решения**:
1. Используйте кэширование данных:
   ```bash
   python main.py --start-date 2020-01-01 --end-date 2020-01-03
   # При повторном запуске данные будут загружены из кэша
   ```

2. Ограничьте временной диапазон:
   ```bash
   # Вместо месяца - несколько дней
   python main.py --start-date 2020-01-01 --end-date 2020-01-03
   ```

3. Уменьшите пространственный регион:
   ```yaml
   region:
     north: 85.0   # Вместо 90.0
     south: 70.0
     east: 180.0
     west: -180.0
   ```

4. Используйте меньшее разрешение сетки:
   ```yaml
   data:
     sources:
       ERA5:
         grid_resolution: 0.5  # Вместо 0.25
   ```

### Проблемы с обнаружением

#### Нет обнаруженных циклонов

**Симптомы**:
- Сообщение: "Не найдено кандидатов в циклоны"
- Пустые результаты анализа

**Причины**:
1. Слишком строгие параметры критериев обнаружения
2. Неподходящий временной период (нет циклонов)
3. Ошибки в параметрах региона
4. Проблемы с входными данными

**Решения**:
1. Проверьте параметры критериев:
   ```yaml
   detection:
     criteria:
       pressure_minimum:
         enabled: true
         pressure_threshold: 1020.0  # Увеличьте порог
         gradient_threshold: 0.1     # Уменьшите порог градиента
   ```

2. Выберите другой временной период:
   ```bash
   # Попробуйте период с известными циклонами
   python main.py --start-date 2020-02-15 --end-date 2020-02-20
   ```

3. Проверьте параметры региона:
   ```yaml
   detection:
     min_latitude: 60.0  # Уменьшите минимальную широту
   ```

4. Включите режим отладки для проверки данных:
   ```bash
   python main.py --debug-plot --log-level DEBUG
   ```

#### Ошибки в критериях обнаружения

**Симптомы**:
- Сообщения об ошибках в конкретных критериях
- Частичные результаты обнаружения

**Причины**:
1. Неправильные параметры критериев
2. Отсутствие необходимых переменных в данных
3. Ошибки в реализации критериев

**Решения**:
1. Проверьте параметры критериев:
   ```yaml
   detection:
     criteria:
       vorticity:
         enabled: true
         vorticity_threshold: 1e-5  # Проверьте порядок величины
         pressure_level: 850        # Убедитесь, что уровень доступен
   ```

2. Убедитесь, что необходимые переменные запрошены:
   ```yaml
   data:
     sources:
       ERA5:
         variables: ['z', 'u', 'v', 't', 'vo', 'msl']  # Все необходимые переменные
   ```

3. Включите отладочный вывод:
   ```bash
   python main.py --log-level DEBUG
   ```

### Проблемы с трекингом

#### Пустые результаты трекинга

**Симптомы**:
- Сообщение: "Найдено 0 треков циклонов"
- Нет связанных треков несмотря на обнаруженные циклоны

**Причины**:
1. Слишком строгие параметры трекинга
2. Недостаточное количество обнаруженных циклонов
3. Ошибки в параметрах фильтрации

**Решения**:
1. Ослабьте параметры трекинга:
   ```yaml
   tracking:
     max_distance: 800.0    # Увеличьте максимальное расстояние
     max_time_gap: 24.0     # Увеличьте временной разрыв
     max_pressure_change: 30.0  # Увеличьте изменение давления
   ```

2. Уменьшите требования к трекам:
   ```yaml
   tracking:
     min_track_duration: 6.0   # Уменьшите минимальную продолжительность
     min_track_points: 2       # Уменьшите минимальное количество точек
   ```

3. Отключите строгую фильтрацию:
   ```bash
   python main.py --debug-tracking
   ```

#### Ошибки связывания треков

**Симптомы**:
- Сообщения о физически невозможных связях
- Разрывы в треках без видимых причин

**Причины**:
1. Неправильные физические ограничения
2. Ошибки в данных о циклонах
3. Проблемы с алгоритмом трекинга

**Решения**:
1. Проверьте физические ограничения:
   ```yaml
   tracking:
     max_cyclone_speed: 150.0  # Увеличьте максимальную скорость
   ```

2. Включите отладочный режим трекинга:
   ```yaml
   tracking:
     debug_save_csv: true
     debug_dir: "tracking_debug"
   ```

3. Проверьте качество входных данных:
   ```bash
   python main.py --debug-plot
   ```

### Проблемы с визуализацией

#### Ошибки при создании графиков

**Симптомы**:
- Сообщения об ошибках matplotlib или cartopy
- Пустые или неполные изображения
- Проблемы с проекциями карт

**Причины**:
1. Проблемы с установкой библиотек визуализации
2. Неправильные параметры графиков
3. Ошибки в данных

**Решения**:
1. Проверьте установку зависимостей:
   ```bash
   pip install matplotlib cartopy
   ```

2. Обновите библиотеки:
   ```bash
   pip install --upgrade matplotlib cartopy
   ```

3. Проверьте параметры визуализации:
   ```yaml
   visualization:
     default_projection: 'NorthPolarStereo'
     map_resolution: 'low'  # Попробуйте более низкое разрешение
   ```

#### Проблемы с отображением карт

**Симптомы**:
- Отсутствующие элементы карты (береговые линии, границы)
- Неправильные проекции
- Проблемы с координатами

**Причины**:
1. Проблемы с данными о береговых линиях
2. Неправильные параметры проекции
3. Ошибки в координатах данных

**Решения**:
1. Загрузите данные береговых линий:
   ```bash
   # Для cartopy может потребоваться загрузка данных
   python -c "import cartopy; cartopy.config['data_dir']"
   ```

2. Проверьте параметры проекции:
   ```yaml
   visualization:
     default_projection: 'PlateCarree'  # Попробуйте другую проекцию
   ```

3. Убедитесь, что координаты в правильном диапазоне:
   ```python
   # Проверка координат
   print(f"Широта: {min_lat} - {max_lat}")
   print(f"Долгота: {min_lon} - {max_lon}")
   ```

### Проблемы с экспортом

#### Ошибки при сохранении файлов

**Симптомы**:
- Сообщения об ошибках доступа к файлам
- Невозможность сохранить результаты
- Поврежденные файлы экспорта

**Причины**:
1. Недостаточно прав доступа к директории
2. Недостаточно свободного места на диске
3. Неправильные пути к файлам

**Решения**:
1. Проверьте права доступа:
   ```bash
   ls -la output/
   chmod 755 output/
   ```

2. Освободите место на диске:
   ```bash
   df -h
   ```

3. Проверьте пути к файлам:
   ```yaml
   export:
     output_dir: '/absolute/path/to/output'  # Используйте абсолютные пути
   ```

#### Проблемы с форматами экспорта

**Симптомы**:
- Невозможность открыть экспортированные файлы
- Ошибки в структуре данных
- Отсутствие ожидаемых полей

**Причины**:
1. Ошибки в реализации экспортеров
2. Несовместимость версий форматов
3. Проблемы с кодировкой

**Решения**:
1. Проверьте версии библиотек:
   ```bash
   pip list | grep -E "(pandas|netCDF4|geojson)"
   ```

2. Попробуйте другой формат:
   ```yaml
   export:
     formats: ['csv']  # Используйте только CSV
   ```

3. Проверьте кодировку файлов:
   ```python
   # При чтении CSV
   df = pd.read_csv('file.csv', encoding='utf-8')
   ```

## Диагностика и отладка

### Использование режимов отладки

Система предоставляет несколько режимов отладки для диагностики проблем:

#### Режим отладки трекинга

```bash
python main.py --debug-tracking --log-level DEBUG
```

Этот режим сохраняет промежуточные результаты трекинга в CSV файлы для анализа.

#### Режим отладки визуализации

```bash
python main.py --debug-plot --log-level DEBUG
```

Этот режим сохраняет дополнительные изображения для диагностики проблем с визуализацией.

## Производительность

### Оптимизация использования памяти

При работе с большими объемами данных могут возникнуть проблемы с памятью:

#### Использование кэширования

```yaml
data:
  cache_dir: '/fast/storage/path'  # Используйте быстрое хранилище
```

#### Обработка данных по частям

```python
# Вместо загрузки всех данных сразу
# Обрабатывайте данные по временным шагам
for time_step in dataset.time.values:
    cyclones = detector.detect(dataset, time_step)
```

### Ускорение выполнения

#### Параллельная обработка

```python
# Использование multiprocessing для обработки нескольких временных шагов
from multiprocessing import Pool

def process_time_step(time_step):
    return detector.detect(dataset, time_step)

with Pool() as pool:
    results = pool.map(process_time_step, dataset.time.values)
```

#### Оптимизация параметров

```yaml
# Уменьшение размера окон для обработки
detection:
  criteria:
    pressure_minimum:
      window_size: 3  # Вместо 5
```

# Документация по унифицированному критерию скорости ветра

## Обзор

Унифицированный критерий скорости ветра (`UnifiedWindCriterion`) представляет собой улучшенную реализацию критерия обнаружения арктических циклонов на основе скорости ветра. Он объединяет простой подход с пороговым значением и расширенные возможности фильтрации полярных артефактов и многоуровневого анализа данных ветра.

## Основные возможности

1. **Обратная совместимость**: Поддерживает существующие конфигурации `wind_threshold`
2. **Фильтрация полярных артефактов**: Автоматическое исключение ложных срабатываний у Северного полюса
3. **Многоуровневый анализ**: Поддержка данных ветра на разных уровнях (поверхность, 850 гПа и др.)
4. **Настройка порогов**: Разные пороговые значения для разных типов данных ветра
5. **Улучшенная обработка данных**: Сглаживание и фильтрация для уменьшения шума

## Конфигурация

### Базовая конфигурация (обратная совместимость)

```yaml
detection:
  criteria:
    wind_threshold:
      enabled: true
      min_speed: 15.0  # Минимальная скорость ветра (м/с)
```

### Расширенная конфигурация

```yaml
detection:
  criteria:
    wind_threshold:
      enabled: true
      # Простой порог (для обратной совместимости)
      min_speed: 15.0
      
      # Расширенная конфигурация
      thresholds:
        surface: 12.0    # Порог для приповерхностного ветра (10м)
        upper: 15.0      # Порог для верхнего уровня (850гПа)
        default: 15.0    # Порог по умолчанию для других уровней
      
      polar_filtering:
        enabled: true
        exclusion_radius: 2.0  # Радиус исключения вокруг Северного полюса (градусы)
      
      window_size: 3
      smooth_sigma: 1.5
```

## Параметры конфигурации

### Основные параметры

| Параметр | Тип | Описание | Значение по умолчанию |
|----------|-----|----------|----------------------|
| `min_speed` | float | Минимальная скорость ветра для обнаружения (м/с) | 15.0 |
| `thresholds` | dict | Словарь порогов для разных типов данных ветра | см. ниже |
| `polar_filtering` | dict | Конфигурация фильтрации полярных артефактов | см. ниже |
| `window_size` | int | Размер окна для поиска локальных максимумов | 3 |
| `smooth_sigma` | float | Параметр сглаживания поля скорости ветра | 1.5 |

### Пороги для разных типов данных

| Тип | Описание | Значение по умолчанию |
|-----|----------|----------------------|
| `surface` | Приповерхностный ветер (10м) | 12.0 м/с |
| `upper` | Верхний уровень (850гПа) | 15.0 м/с |
| `default` | Уровень по умолчанию | 15.0 м/с |

### Конфигурация фильтрации полярных артефактов

| Параметр | Тип | Описание | Значение по умолчанию |
|----------|-----|----------|----------------------|
| `enabled` | bool | Включена ли фильтрация | true |
| `exclusion_radius` | float | Радиус исключения вокруг полюса (градусы) | 2.0 |

## Рекомендации по настройке

### Для обнаружения арктических мезоциклонов

```yaml
detection:
  criteria:
    wind_threshold:
      enabled: true
      thresholds:
        surface: 12.0    # Более низкий порог для приповерхностного ветра
        upper: 15.0      # Стандартный порог для верхнего уровня
      polar_filtering:
        enabled: true
        exclusion_radius: 2.0
      window_size: 3
      smooth_sigma: 1.5
```

### Для традиционного подхода (обратная совместимость)

```yaml
detection:
  criteria:
    wind_threshold:
      enabled: true
      min_speed: 15.0
```

## Преимущества унифицированного подхода

1. **Снижение ложных срабатываний**: Фильтрация артефактов у полюса
2. **Более точное обнаружение**: Разные пороги для разных типов данных
3. **Обратная совместимость**: Существующие конфигурации продолжают работать
4. **Гибкость настройки**: Возможность тонкой настройки под конкретные задачи
5. **Улучшенная физическая обоснованность**: Соответствие характеристикам арктических мезоциклонов

## Использование в коде

```python
from detection.criteria import UnifiedWindCriterion

# Создание критерия с параметрами по умолчанию
criterion = UnifiedWindCriterion(min_latitude=70.0)

# Создание критерия с расширенными параметрами
criterion = UnifiedWindCriterion(
    min_latitude=70.0,
    thresholds={
        'surface': 12.0,
        'upper': 15.0,
        'default': 15.0
    },
    polar_filtering={
        'enabled': True,
        'exclusion_radius': 2.0
    }
)

# Применение критерия
candidates = criterion.apply(dataset, time_step)
```

## Миграция с EnhancedWindCriterion

Если вы использовали `EnhancedWindCriterion`, просто замените его на `UnifiedWindCriterion`. Конфигурация остается такой же, но теперь поддерживается через основной `wind_threshold` критерий.
